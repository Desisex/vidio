# 🎯 Tambola House

An online Tambola ticket booking system with token-based economy.

## 🚀 Features

- ✅ User Registration & Login
- ✅ Token Deposit System
- ✅ Admin Approval for Deposits
- ✅ 300 Fixed Tickets
- ✅ Ticket Booking (10 Tokens per Ticket)
- ✅ My Bookings
- ✅ Admin Dashboard
- ✅ Real-time Updates

## 🛠️ Tech Stack

- Firebase Authentication
- Firestore Database
- Firebase Storage
- Firebase Hosting
- HTML, CSS, JavaScript

## 📦 Installation

1. Clone the repository
2. Create Firebase project
3. Enable Authentication, Firestore, Storage
4. Update firebase-config.js with your config
5. Deploy to Firebase Hosting

## 🔧 Deployment

```bash
firebase login
